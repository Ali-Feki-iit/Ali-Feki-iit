## Selected projects

### [SmartScanner — Intelligent document assistant](https://github.com/Ali-Feki-iit/SmartScanner)

Helps users access text from physical documents through mobile OCR, multilingual translation and text-to-speech.

**Capabilities:** camera and gallery input, English/French/Arabic translation, configurable speech playback.

`Flutter` · `Dart` · `Google ML Kit`

### [Shopflow — E-commerce platform frontend](https://github.com/Ali-Feki-iit/frontend-angular)

Organizes the shopping experience around distinct customer, seller and administrator workflows.

**Capabilities:** role-based interfaces, REST API integration and JWT authentication.

`Angular` · `TypeScript` · `RxJS` · `Angular Material`

### [Dhawna TN — Civic technology prototype](https://github.com/Ali-Feki-iit/dhawna-tn)

Explores how citizens could report and visualize electricity outages in Tunisia through an interactive map and dashboard.

**Capabilities:** geographic visualization, reporting, filtering and CSV export. Uses simulated data; not a live monitoring service.

`JavaScript` · `Leaflet` · `OpenStreetMap`
